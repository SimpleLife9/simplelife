Transcripción local de voz

Laboratorio técnico con Whisper Tiny multilingüe, Transformers.js y WebAssembly (CPU). El modelo se descarga una vez y queda en la caché privada del navegador cuando el navegador lo permite.

Usa únicamente audio sintético o público de prueba. No selecciones ninguno de tus audios privados ni grabaciones personales. Este laboratorio no está aprobado para procesar los originales.
Privacidad: el audio elegido se decodifica y se procesa dentro de esta pestaña. El audio elegido se procesa íntegramente en esta pestaña y nunca se envía al Worker. El código bloquea solicitudes fetch de escritura (POST/PUT/PATCH/DELETE). El motor y los pesos públicos se descargan mediante el Worker del mismo dominio, que solo permite GET/HEAD a archivos de una revisión fija. No usa micrófono, Supabase, ARIA ni un servicio de transcripción remoto.

1. Preparar motor y modelo

Whisper Tiny multilingüe · revisión fija ff417702 · pesos Q8 aproximados: 40,8 MB, más runtime WASM. Se ejecuta con un hilo CPU.

Motor sin cargar. La descarga solo comienza al pulsar el botón.
—Persistencia de caché
—Memoria del dispositivo (estimación del navegador)
—Heap JS (no incluye toda la memoria WASM)

2. Probar un audio sintético

Selecciona un archivo breve de prueba (máximo 25 MiB y 3 minutos). El archivo no se sube; se convierte a mono/16 kHz localmente.

La transcripción aparecerá aquí.

—Tiempo de inferencia
—Error de palabras frente a referencia (si se introduce)

La cifra WER es solo una métrica aproximada de esta muestra; no certifica precisión en español cubano ni en audios reales.

Estado experimental. No se conecta a la cola privada ni crea capturas. Cierra la pestaña o pulsa «Liberar memoria» para terminar la sesión.
