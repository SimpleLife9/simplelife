Transcripción local de voz

Laboratorio con whisper.cpp + WebAssembly SIMD. Usa el modelo Tiny multilingüe cuantizado Q5_1 (32,2 MB): se descarga una vez y queda guardado en IndexedDB para reutilizarlo sin volver a consumir descarga en cada sesión.

Usa únicamente audio sintético o público de prueba. No selecciones audios privados ni grabaciones personales. Este laboratorio no está aprobado para procesar originales.
Privacidad: el audio se decodifica y procesa en esta pestaña. Nunca se envía al Worker ni a un servicio de inferencia. El Worker existente solo transmite el archivo público del modelo, de una revisión fija, mediante GET/HEAD. El motor se obtiene de jsDelivr al pulsar preparar; no se usa micrófono, Supabase, ARIA ni un servicio de transcripción remoto.

1. Preparar motor y modelo

Modelo: ggml-tiny-q5_1.bin · revisión fija 0b364b56 · SHA-256 verificado antes de inicializar · CPU local, 2 hilos.

2. Probar un audio sintético

Selecciona un archivo breve (máximo 25 MiB y 2 minutos). Se convierte a mono/16 kHz y se procesa localmente. La inferencia no consume solicitudes de una API ni créditos por minuto.
